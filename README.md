# swapnilsingh.co.in

Personal research website of Swapnil Kumar Singh. GitHub Pages publishes the `main` branch directly (Settings → Pages → Deploy from a branch); `.nojekyll` makes it serve the files exactly as built. The `Check site` workflow only runs the checks below.

## How it is built

All text lives in three data files. A small Python script (standard library only) turns them into the pages.

| File | What it holds |
| --- | --- |
| `content/profile.json` | Bio, links, education, appointments, activities, skills |
| `content/publications.json` | Journal articles, preprints, papers under review, talks |
| `content/projects.json` | Research fields and the project records |

To change anything, edit the JSON and run:

```sh
python3 tools/build.py      # regenerates every page and sitemap.xml
node tools/check-site.mjs   # links, metadata, sitemap
node tools/test-site.mjs    # structure, fonts, publications, redirects
```

Then commit and push. The `Check site` workflow fails if the pages are out of date with `content/`.

## Design

The site is typeset like a physics paper: Latin Modern for titles and mathematics, Crimson Pro for reading text, Fira Sans for the interface. All fonts are self-hosted in `assets/fonts/` (licences included), so no requests go to Google.

- `assets/v3/site.css`: the only stylesheet
- `assets/v3/site.js`: header, mobile menu, live visitor count
- `assets/v3/fold.js`: the interactive figure on the homepage
- `assets/blackhole-gateway-v3.js`: the live black-hole render (WebGL2)
- `research/kahler-stability-wall/`: the interactive companion to arXiv:2611.08491 (`atlas-v3.css` brings it onto the site's type and palette)

## Visitor count

The footer shows a live unique-visitor total from GoatCounter (cookie-free, no ads). Set the site code in `GOATCOUNTER` at the top of `assets/v3/site.js`; until then the line stays hidden.

## Retired pages

`world`, `news`, `ideas`, `projects`, `private`, `quiet-hours`, `cosmology`, `computation` and `engineering` are now small redirect pages generated by `tools/build.py`, so old links keep working.
