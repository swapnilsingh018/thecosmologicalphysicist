Who is responsible

This is the personal research website of Swapnil Kumar Singh, Florence, Italy. Write to swapnilsingh.ph@gmail.com with any privacy question.

Visitor statistics

Visits are counted with GoatCounter, which uses no cookies and does not store IP addresses. It records the page visited, the referring site, browser type, screen size and approximate country, and uses a short-lived hash to count each visitor once. The total number of unique visitors is shown at the foot of each page. The legal basis is a legitimate interest in knowing, in aggregate, how the site is used (Art. 6(1)(f) GDPR).

Hosting and other services

The site is hosted on GitHub Pages, which processes connection data such as IP addresses to deliver pages (GitHub privacy statement). All typefaces are served from this site; nothing is loaded from Google. Pages that list publications ask the public INSPIRE-HEP database for current citation counts; that request contains no personal data beyond what any web request carries. Links to arXiv, INSPIRE-HEP, journals, GitHub and LinkedIn lead to sites with their own policies.

Email

If you write to me, I use your message and address only to reply, and keep them no longer than the conversation needs.
